* Авторизация


В этом разделе вы узнаете как получить токен доступа и авторизовать запросы к GigaChat API.
URL для подключения?
С 17 июля 2026 года для подключения к GigaChat API используется адрес — https://api.giga.chat. Он является целевым URL для всех пользователей: физических и юридических лиц.
Если вы подключились до 17 июля 2026 года, вы можете продолжать использовать прежний адрес https://gigachat.devices.sberbank.ru/ — он остается доступным.
При этом прежний URL больше не используется для новых подключений и в дальнейшем будет выведен из эксплуатации. Поэтому рекомендуем запланировать переход на https://api.giga.chat.
Получение токена доступа?
Чтобы получить токен, отправьте запрос POST /api/v2/oauth:
curl -L -X POST 'https://ngw.devices.sberbank.ru:9443/api/v2/oauth' \
-H 'Content-Type: application/x-www-form-urlencoded' \
-H 'Accept: application/json' \
-H 'RqUID: <идентификатор_запроса>' \
-H 'Authorization: Basic ключ_авторизации' \
--data-urlencode 'scope=GIGACHAT_API_PERS'

Где:
* RqUID — обязательный заголовок, в котором нужно передать уникальный идентификатор запроса в формате uuid4. Идентификатор нужно указать самостоятельно, для этого можно использовать стандартные библиотеки и классы для генерации UUID и GUID.
* Authorization — обязательный заголовок, в котором нужно передать ключ авторизации.
* scope — обязательное поле в теле запроса, которое указывает, к какой версии API выполняется запрос. Возможные значения:
o GIGACHAT_API_PERS — доступ для физических лиц.
o GIGACHAT_API_B2B — доступ для ИП и юридических лиц по платным пакетам.
o GIGACHAT_API_CORP — доступ для ИП и юридических лиц по схеме pay-as-you-go.
При успешном выполнении запроса GigaChat API вернет токен доступа, который действует в течение 30 минут:
{

  "expires_at": 1679471442
}

Запросы на получение токена можно отправлять до 10 раз в секунду.
Как получить ключ авторизации и токен доступа читайте в разделах Быстрый старт для физических лиц и Быстрый старт для ИП и юридических лиц.
Авторизация запросов?
Для авторизации запросов передавайте токен доступа в заголовке Authorization.
Пример запроса на получение списка моделей:
curl -L -X GET 'https://api.giga.chat/v1/models' \
-H 'Accept: application/json' \
-H 'Authorization: Bearer <токен_доступа>'
