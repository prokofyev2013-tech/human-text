# Текст по-человечески

Анонимный веб-инструмент, который помогает разложить сумбурные мысли по полочкам и подготовиться к разговору с психологом.

Приложение сохраняет все факты, имена и числа из вашего текста, но переформулирует хаотичное изложение в спокойную, структурированную картину с бережными гипотезами. Диагнозы не ставит, терапию не заменяет.

Документы проекта (ТЗ, промт для разработчика, дизайн-гайд) лежат в папке [`dokuments/`](dokuments/).

---

## Что умеет

- Принимает текст от 10 до 5000 знаков, показывает счётчик и блокирует превышение лимита.
- Отдаёт результат тремя блоками: «Что происходит», «Что, возможно, за этим стоит», «О чём поговорить с психологом».
- Распознаёт «красные флаги» (суицидальные мысли, самоповреждение, насилие, острый кризис) и показывает бережное предупреждение с телефоном доверия.
- Копирует результат одним нажатием, показывает тост «Скопировали».
- Работает анонимно: без регистрации, без сбора персональных данных, тексты не сохраняются.
- Ограничивает частоту запросов: 5 в минуту с одного IP.
- Полностью адаптивен от 320px, доступен с клавиатуры и скринридеров.

### Два режима работы

| Режим | Когда включается | Что делает |
|-------|------------------|-----------|
| **LLM** | Задан `LLM_API_KEY` (или `GIGACHAT_CLIENT_ID` + `GIGACHAT_CLIENT_SECRET`) в `.env` | Отправляет текст в GigaChat с подготовленным промптом |
| **Локальный** | Ключ не задан или модель недоступна | Собирает результат на правилах: темы, гипотезы, факты |

Локальный режим — это не заглушка: он выдаёт осмысленный текст и сохраняет все имена и числа. Если LLM падает, приложение автоматически переключается на него, поэтому пользователь всегда получает результат.

### Подключение GigaChat

В `.env` достаточно одного из двух:

- **Вариант A** — готовый «Ключ авторизации» (Base64 из личного кабинета) в `LLM_API_KEY`;
- **Вариант B** — `GIGACHAT_CLIENT_ID` + `GIGACHAT_CLIENT_SECRET`: приложение само соберёт из них Basic-ключ.

Проверить живое подключение без запуска приложения:

```bat
.venv\Scripts\python.exe _check_api.py
```

Скрипт по шагам проверяет OAuth, список моделей и тестовый запрос к `chat/completions`.

### Бот ВКонтакте (отчёты о запросах)

Приложение умеет слать в сообщество ВКонтакте сводку по каждому запросу: кто (IP), когда (UTC), режим (LLM/локальный) и сколько токенов потрачено. Работает через Long Poll API — вебхуки и публичный адрес не нужны.

**Что умеет бот:**

- на каждый запрос приложения присылает уведомление в указанный диалог (`VK_NOTIFY_PEER_ID`);
- по команде **«статистика»** в личных сообщениях сообщества присылает сводку: всего запросов, prompt/completion/total токены, последние запросы;
- по команде **«сброс»** (только администраторы) обнуляет счётчик.

**Настройка за 5 шагов:**

1. Создайте сообщество ВКонтакте → «Управление» → «Настройки» → «Работа с API».
2. Создайте ключ с правами: `messages`, `groups`, `stats` (сервисный токен сообщества, бессрочный).
3. Включите в сообществе: «Управление» → «Настройки» → «API» → **Long Poll API** → версия 5.199, и разрешите событие «Сообщение получено» (message_new).
4. Включите «Сообщения сообщества» («Управление» → «Сообщения»), иначе бот не сможет отвечать.
5. Впишите в `.env`: `VK_API_TOKEN`, `VK_GROUP_ID`, а при желании `VK_NOTIFY_PEER_ID` и `VK_ADMIN_IDS`.

Без `VK_API_TOKEN` бот не запускается и приложение работает как раньше. Данные хранятся только в памяти процесса и не включают тексты пользователей.

## Стек

- **Backend:** Python 3.12, FastAPI, Pydantic v2, httpx
- **Frontend:** ванильные HTML, CSS и ES-модули — без сборки и без зависимостей
- **Тесты:** pytest (53 теста)

Фронтенд намеренно сделан без Node.js: приложение запускается одной командой и не требует установки npm-пакетов.

## Запуск

### 1. Виртуальное окружение

Windows (cmd):

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройки

```bat
copy .env.example .env
```

Откройте `.env`. Для работы с языковой моделью заполните `LLM_API_KEY`. Без ключа приложение сразу запустится в локальном режиме.

### 3. Старт

```bat
.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

Документация API — [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

### 4. Тесты

```bat
.venv\Scripts\python.exe -m pytest
```

## API

### `POST /api/structure-text`

Запрос:

```json
{ "text": "строка с текстом пользователя" }
```

Ответ `200`:

```json
{
  "structuredText": "Что происходит\n...\n\nЧто, возможно, за этим стоит\n— ...",
  "sections": [
    { "title": "Что происходит", "body": "..." },
    { "title": "Что, возможно, за этим стоит", "bullets": ["...", "..."] },
    { "title": "О чём поговорить с психологом", "body": "..." }
  ],
  "hasRedFlags": false,
  "processingTime": 0.42
}
```

Ошибки:

| Код | Причина | Тело |
|-----|---------|------|
| `400` | Пустой текст, короче 10 или длиннее 5000 знаков | `{"error": "..."}` |
| `422` | Не передан параметр `text` | стандартный ответ FastAPI |
| `429` | Превышен лимит запросов | `{"error": "..."}` + заголовок `Retry-After` |
| `504` | Модель не ответила за 30 секунд | `{"error": "..."}` |

### `GET /api/health`

```json
{
  "status": "ok",
  "llmEnabled": false,
  "limits": { "minTextLength": 10, "maxTextLength": 5000 }
}
```

## Как устроен результат

Локальный структуратор определяет темы по ключевым словам (работа, отношения, семья, одиночество, тревога, самооценка и другие), затем собирает:

1. **Общую картину** — первый смысловой фрагмент текста плюс названия найденных тем и упомянутый возраст.
2. **2–4 гипотезы** — только с модальными оборотами: «возможно», «кажется», «вероятно», «может быть».
3. **Темы для психолога** — что именно имеет смысл обсудить.

Отдельной строкой выводятся сохранённые факты: имена и числа из исходного текста. Это делает сохранность проверяемой — на этом построены тесты `tests/test_facts.py`.

---

## Приватность

- Тексты пользователей не сохраняются ни в базе, ни в логах.
- В логах остаются только технические события: тип ошибки, срабатывание лимита.
- Ключ LLM живёт только в переменных окружения сервера и никогда не попадает на клиент.
- Персональные данные не запрашиваются: нет ни регистрации, ни форм с именем или почтой.

---

## Ограничения демонстрационной версии

- Телефон доверия указан один (`8-800-2000-122`) — для реального релиза нужен юридически проверенный список.
- Хранение состояния лимитера — в памяти процесса: при нескольких воркерах счётчики не общие.
- Тёмной темы нет.
- Локальный структуратор — эвристика, а не замена языковой модели: при наличии ключа качество текста заметно выше.
