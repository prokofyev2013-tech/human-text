**Версия:** 1.0
**Дата:** 24 ноября 2026 г.
**Для кого документ:** фронтенд-разработчик, дизайнер, QA
**Основа:** ТЗ v1.1 и промт для разработчика (в этой же папке)

## 1. Что это за дизайн

Одна страница, три блока, одна кнопка. Человек вставляет сумбурный текст — получает аккуратный, структурированный. Больше ничего делать не надо.

**Пять правил, по которым всё построено:**

1. **Один экран — одно действие.** Пользователь никогда не выбирает между двумя кнопками.
2. **Текст важнее декора.** Никаких фоновых узоров, рамок-рисуночков, теней «для красоты».
3. **Всё по сетке.** Одинаковые отступы, одинаковые интервалы между строками, блоки явно отделены пустотой.
4. **Три цвета. Два шрифта.** Если хочется четвёртый цвет — значит, нужен оттенок одного из трёх.
5. **Спокойствие.** Ничего не мигает, не пульсирует, не прыгает. Движение только «мягкое появление».

## 2. Цветовая палитра

### 2.1. Три базовых цвета

| Роль | Название | HEX | Где используется |
|------|----------|-----|------------------|
| Фон / «бумага» | **Sand** | `#F6F3EE` | Фон страницы, фон поля ввода |
| Текст / «чернила» | **Ink** | `#2B3440` | Весь текст, иконки, обводки |
| Акцент / «действие» | **Harbor** | `#3A7CA5` | Главная кнопка, ссылки, фокус, статус-подсветка |

Четвёртых hues нет. Всё остальное — оттенки и прозрачные версии этих трёх.

### 2.2. Производные (разрешённые, потому что это те же три цвета)

| Токен | Значение | Как получено | Зачем |
|-------|----------|--------------|-------|
| `bg` | `#F6F3EE` | Sand 100% | Фон страницы |
| `bg-card` | `#FFFFFF` | Sand, высветленный до бумаги | Карточка результата |
| `bg-tint` | `#EDE7DE` | Sand +12% темнее | Фон вторичных кнопок, disabled-поля |
| `bg-warning` | `#EDE4D6` | Sand +8% темнее, тёплее | Фон блока «красных флагов» — спокойный, не красный |
| `ink` | `#2B3440` | Ink 100% | Основной текст |
| `ink-soft` | `rgba(43,52,64,0.68)` | Ink 68% | Вторичный текст, плейсхолдер, счётчик |
| `ink-faint` | `rgba(43,52,64,0.45)` | Ink 45% | Подсказки, caption |
| `line` | `rgba(43,52,64,0.16)` | Ink 16% | Разделители, обводка поля |
| `line-strong` | `rgba(43,52,64,0.40)` | Ink 40% | Обводка поля в фокусе |
| `accent` | `#3A7CA5` | Harbor 100% | Главная кнопка |
| `accent-hover` | `#326B90` | Harbor −10% яркости | Наведение |
| `accent-soft` | `rgba(58,124,165,0.10)` | Harbor 10% | Фон сабмита-подложки, чипы |
| `on-accent` | `#FFFFFF` | Белый | Текст на кнопке |

### 2.3. Проверка контраста (WCAG 2.1 AA, нужно ≥ 4.5:1)

| Пара | Контраст | Итог |
|------|----------|------|
| `ink` на `bg` | 11.1:1 | ✅ |
| `ink-soft` на `bg` | 6.6:1 | ✅ |
| `ink-faint` на `bg` | 3.6:1 | ⚠️ только для текста ≥ 24px (крупный caption), не для основного |
| `on-accent` на `accent` | 4.6:1 | ✅ |
| `ink` на `bg-card` | 13.1:1 | ✅ |
| `ink` на `bg-warning` | 9.6:1 | ✅ |
| `accent` на `bg` | 4.6:1 | ✅ для ссылок |
| Обводка `line-strong` на `bg` | 2.4:1 | ✅ (минимум 3:1 для графических элементов — усиливается до 0.40 alpha в фокусе) |

**Запрещено:** чистый чёрный `#000`, чистый красный `#E53935`, градиенты, тени с цветным подтоном.

### 2.4. Распределение цвета по площади

- 85% — `bg` / `bg-card` (песок и бумага)
- 12% — `ink` (текст)
- 3% — `accent` (единственная кнопка + фокус)

Акцент должен быть один на экране. Если акцентов два — один из них лишний.

## 3. Типографика

### 3.1. Два шрифта

| Шрифт | Вес | Начертание | Для чего |
|-------|-----|-----------|----------|
| **Inter** | 400, 500, 600 | sans-serif | Всё: текст, UI, кнопки, поля |
| **Manrope** | 600, 700 | sans-serif | Только заголовки: H1 и H2 блоков |

Подключение: Google Fonts, `display=swap`, только latin + cyrillic.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&family=Manrope:wght@600;700&display=cyrillic,swap" rel="stylesheet">
```

**Фолбэк-стек:** `'Inter', 'Manrope', system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif`.

### 3.2. Шкала (модулярная, база 16px, шаг 1.25)

| Стиль | Размер | Line-height | Вес | Треккинг | Где |
|-------|--------|-------------|-----|----------|-----|
| `h1` | 32px / 20px mobile | 1.25 | Manrope 700 | −0.02em | Название приложения |
| `h2` | 24px / 20px mobile | 1.3 | Manrope 600 | −0.01em | «Общая картина», «Возможные гипотезы» |
| `body-lg` | 18px | **1.7** | Inter 400 | 0 | Ввод пользователя и результат |
| `body` | 16px | **1.7** | Inter 400 | 0 | Дисклеймер, подписи, кнопки |
| `caption` | 14px | 1.5 | Inter 500 | 0.01em | Счётчик знаков, подвал |
| `button` | 17px / 16px mobile | 1.2 | Inter 600 | 0.01em | Все кнопки |

### 3.3. Правила текста

- **Line-height 1.7 для всего, что читают.** Поля и результат — обязательно.
- **Максимальная ширина строки — 68 символов** (`max-width: 68ch`). Дольше — глаза устают.
- **Никогда не выравнивать по правому краю и по ширине.** Только `text-align: left`.
- **Заголовки не заглавными буквами.** `text-transform: uppercase` запрещено.
- **Жирный — только для заголовков и названий полей.** Внутри результата жирным выделять нельзя.
- Минимальный читаемый размер — 14px. Мельче нигде.

## 4. Сетка, отступы, размеры

### 4.1. Отступы (шкала 8px, только эти значения)

| Токен | Значение | Применение |
|-------|----------|-----------|
| `space-1` | 4px | Между иконкой и подписью |
| `space-2` | 8px | Внутри кнопки, отступ счётчика |
| `space-3` | 16px | Внутренний отступ полей, padding mobile |
| `space-4` | 24px | Padding карточек |
| `space-5` | 32px | Между связанными блоками |
| `space-6` | 48px | Между крупными секциями |
| `space-7` | 64px | От шапки до первого блока |
| `space-8` | 96px | Отступ снизу страницы (desktop) |

**Правило:** внутри блока `space-3`/`space-4`, между блоками `space-5`, между секциями `space-6`. Никаких 20px, 28px, 36px — только из таблицы.

### 4.2. Интервал между строками и абзацами

- Строки в тексте: `line-height: 1.7` (см. §3.2).
- Абзацы внутри результата: `margin-bottom: space-3` (16px). **Пустая строка через `<br>` запрещена.**
- Между списком гипотез и следующим заголовком: `space-4`.
- Между заголовком блока и его текстом: `space-2` (8px) — заголовок «прилипает» к своему тексту.

### 4.3. Контейнер и брейкпоинты

| Брейкпоинт | Ширина контейнера | Горизонтальный padding |
|-----------|-------------------|------------------------|
| `< 375px` | 100% | 16px |
| `375–767px` (mobile) | 100%, max 560px | 16px |
| `768–1199px` (tablet) | 640px | 24px |
| `≥ 1200px` (desktop) | **720px** | 24px |

Контент **никогда** не шире 720px. Это ключевой приём «пустого пространства»: по бокам много воздуха, колонка узкая и спокойная.

### 4.4. Радиусы, обводки, тени

| Токен | Значение |
|-------|----------|
| `radius-sm` | 10px — чипы, вторичные кнопки |
| `radius-md` | 14px — поле ввода |
| `radius-lg` | 20px — карточки результата и предупреждения |
| `radius-pill` | 999px — главная кнопка |
| `border` | 1.5px solid `line` |
| `border-focus` | 2.5px solid `accent` |
| `shadow-sm` | `0 1px 2px rgba(43,52,64,0.06)` |
| `shadow-md` | `0 6px 20px rgba(43,52,64,0.08)` — только карточка результата |

Теней максимум две на экране. Тени не цветные.

## 5. Компоненты

### 5.1. Главная кнопка «Структурировать мысли»

| Параметр | Значение |
|----------|----------|
| Высота | 56px desktop / 52px mobile |
| Padding | 0 32px |
| Радиус | `radius-pill` |
| Фон | `accent` |
| Текст | `button` 17px Inter 600, `on-accent` |
| Ширина | 100% контейнера (не «по тексту» — крупная и понятная) |
| Минимальная зона нажатия | 44×44px — соблюдено |

Состояния:

| Состояние | Что меняется |
|-----------|-------------|
| `default` | Фон `accent` |
| `hover` | Фон `accent-hover`, `transform: translateY(-1px)`, `shadow-md` |
| `active` | `transform: translateY(0)`, `shadow-sm` |
| `focus-visible` | Обводка 3px `accent` + offset 3px |
| `disabled` | Фон `bg-tint`, текст `ink-faint`, обводка `line`, `cursor: not-allowed`. **Не серая «немая» — именно видимая неактивная кнопка** |
| `loading` | Текст «Проясняю мысли…», спиннер слева (см. §5.6), кнопка не кликается |

Правило: disabled пока длина текста < 10 знаков.

### 5.2. Вторичная кнопка («Начать заново», «Повторить»)

- Высота 48px, радиус `radius-sm`, фон прозрачный, обводка 1.5px `line-strong`, текст `ink`.
- Hover: фон `bg-tint`.
- Никогда не стоит рядом с главной кнопкой одинакового размера: вторичная уже или уже по весу.

### 5.3. Поле ввода

| Параметр | Значение |
|----------|----------|
| Фон | `bg-card` |
| Обводка | 1.5px `line` |
| Радиус | `radius-md` |
| Padding | 16px |
| Минимальная высота | 180px desktop / 200px mobile |
| Максимальная высота | 480px, дальше внутренний скролл |
| Автоувеличение | По содержимому, `min-height` фиксирован, `max-height` ограничен |
| Текст | `body-lg` 18px, line-height 1.7, `ink` |
| Плейсхолдер | `body-lg`, `ink-soft` |
| Focus | Обводка 2.5px `accent`, фон `bg-card`, без тени «свечения» |

Плейсхолдер: «Опишите вашу ситуацию или вопрос так, как приходит в голову...»

### 5.4. Счётчик знаков

- Расположение: справа под полем, `caption` 14px Inter 500, цвет `ink-faint`.
- Формат: `1240 / 5000`.
- При > 4500 знаков: цвет становится `ink` (не красный — усиление контраста, не смена hues).
- При попытке вставить больше 5000: ввод обрезается, под полем на 3 секунды появляется подсказка `caption` цветом `ink`: «Можно не больше 5000 знаков — самое важное поместится».
- Счётчик связан с полем через `aria-describedby`.

### 5.5. Карточка результата

| Параметр | Значение |
|----------|----------|
| Фон | `bg-card` |
| Обводка | 1px `line` |
| Радиус | `radius-lg` |
| Padding | 24px mobile / 32px desktop |
| Тень | `shadow-md` |
| Текст | `body-lg` 18px, line-height 1.7 |
| Ширина | 100% контейнера |

Внутри — три секции с `h2` (Manrope 600) и `space-5` между ними:
1. «Что происходит» — общая картина.
2. «Что, возможно, за этим стоит» — 2–4 гипотезы списком.
3. «О чём поговорить с психологом» — короткий абзац.

Список гипотез: маркеры — тире `–`, отступ слева 24px, между пунктами `space-2`, висячие строки выровнены.

Кнопки под результатом: «Скопировать» (главная, но уже 48px — не конкурирует с первой) и «Начать заново» (вторичная). На mobile — вертикально, одна под другой, обе на всю ширину, `space-2` между.

Результат **не редактируется**: это `<div role="region">`, а не `<textarea>`.

### 5.6. Индикатор ожидания

**Без пульсации и мигания** (по ТЗ v1.1).

- Спиннер: окружность 20px, обводка 2.5px, `line` + сегмент `accent`, вращение 900ms linear infinite.
- Текст справа: «Проясняю мысли...», `body` 16px, `ink-soft`.
- Расположение: внутри главной кнопки (loading-состояние), чтобы кнопка не «прыгала».
- Дополнительно под полем — три статичные точки-строки скелетона цветом `bg-tint`. **Скелетон не переливается** — просто серые полосы.
- `prefers-reduced-motion: reduce` → спиннер заменяется текстом «Проясняю мысли...» без вращения.

### 5.7. Блок «красных флагов»

Появляется **под** результатом, не вместо.

| Параметр | Значение |
|----------|----------|
| Фон | `bg-warning` (тёплый песок, **не красный**) |
| Обводка | 1.5px `rgba(43,52,64,0.22)` |
| Радиус | `radius-lg` |
| Левая акцентная полоса | 4px `ink` (не красная) |
| Padding | 24px |
| Иконка | 24×24 inline SVG: «сердце/разговор», штриховая, `ink`. Без восклицательного знака и без крестов |
| Заголовок | `h2` 20px Manrope 600 |
| Текст | `body` 16px, line-height 1.7 |
| Телефон доверия | Крупная ссылка-кнопка 48px, `accent` на `bg-card`, `font-weight: 600` |

Текст блока: «Похоже, тут тяжело и одному не разобраться. Это не страшно и не надолго — но с этим важно поговорить с живым человеком. Вот куда можно позвонить прямо сейчас, бесплатно и круглосуточно.»

Блок не закрывается, не появляется с анимацией «выпрыгивания». Плавное появление `opacity 0→1, 240ms`.

### 5.8. Тост «Скопировали»

- Текст: «Скопировали».
- Появляется внизу по центру, `bg-card`, обводка `line`, `radius-sm`, padding 12px 20px, `shadow-md`.
- Иконка галочка 18px `accent`.
- Анимация: `translateY(8px)→0` + `opacity 0→1`, 200ms. Держится 2000ms, уходит 200ms.
- `aria-live="polite"`, чтобы скринридер озвучил.
- Не блокирует клики (`pointer-events: none` на контейнер).

### 5.9. Сообщение об ошибке

- Фон `bg-card`, обводка 1.5px `line-strong`, радиус `radius-lg`, padding 24px.
- Иконка: штриховой «вопрос в круге», `ink`. Никаких крестов и красного.
- Заголовок `h2`: «Не получилось».
- Текст `body`: «Что-то пошло не так на нашей стороне. Ваш текст никуда не делся — попробуйте ещё раз.»
- Кнопка «Повторить» (вторичная) + кнопка «Начать заново» (вторичная).
- При `429`: «Вы отправляете слишком часто. Подождите минуту и попробуйте снова.»
- При `400` (< 10 знаков): не ошибка, а подсказка под полем цветом `ink`: «Напишите хотя бы пару предложений — так выйдет лучше.»

### 5.10. Дисклеймер

- Всегда виден, над полем ввода.
- Фон `bg-tint` (или без фона), обводки нет, радиус `radius-sm`, padding 16px.
- Текст `body` 16px, `ink-soft`, line-height 1.7.
- Формулировка простая: «Это не терапия. Здесь можно разобрать мысли по полочкам и подготовиться к разговору с психологом. Диагнозы мы не ставим и не заменяем специалиста.»
- Не исчезает после генерации — остаётся сверху.

### 5.11. Шапка

- Одна строка: название «Текст по-человечески» (`h1`, Manrope 700) + слева небольшая иллюстрация 40×40 (см. §7).
- Высота 64px mobile / 80px desktop, `border-bottom: none` — отделяется только пустотой `space-6`.
- Никакого меню, никаких ссылок, никаких иконок настроек.

### 5.12. Подвал

- Одна строка `caption`, `ink-faint`: «Мы не сохраняем ваши тексты.»
- `space-8` сверху.


Колонка 720px центрируется. По бокам — пустой `bg`. Никаких боковых панелей, сайдбаров, «популярных запросов».

### 6.3. Порядок секций и логика появления

| Состояние | Что видно |
|-----------|-----------|
| Empty | Шапка, дисклеймер, поле, счётчик, кнопка (disabled) |
| Loading | + кнопка в loading-состоянии, скелетон под ней |
| Success | + карточка результата |
| Red Flag | + блок предупреждения под результатом |
| Error | + карточка ошибки вместо результата (поле сохранено) |

Поле ввода **не скрывается** после генерации — результат появляется под ним. Это даёт «начать заново» без потери контекста.

## 7. Иллюстрации

### 7.1. Правила

- **Формат: 2D вектор** (SVG / EPS / AI, скачанный со стока и сконвертированный в SVG).
- **Стиль:** тонкая штриховая линия (line art, stroke 1.5–2px), без залитий, без градиентов, без 3D, без «мультяшных» маскотов и без реалистичных людей.
- **Цвет:** монохром — `ink` для линий, максимум один `accent` на детали. Никаких разноцветных иллюстраций: это сломало бы правило трёх цветов.
- **Фон иллюстрации — прозрачный.** Никаких белых плашек и прямоугольников вокруг.
- **Максимум 2 иллюстрации на весь экран.** Больше — визуальный шум.
- Все иллюстрации — **декоративные**, `aria-hidden="true"`, если рядом есть текст. Если иллюстрация несёт смысл — обязательен `<title>` внутри SVG или `alt`.

### 7.2. Слоты иллюстраций

| # | Куда | Размер | Что изображено | Поисковый запрос на стоке |
|---|------|--------|---------------|---------------------------|
| I1 | Шапка, логотип-марка | 40×40 (mobile 32×32) | Два пересеющихся мягких контура: «речевое облако → аккуратный список». Смысл: сумбур становится порядком | `line icon abstract speech bubble to list minimal vector` |
| I2 | Empty state, под полем ввода (показывается только когда поле пустое) | 200×160, desktop / 160×128 mobile | Открытая тетрадь и разбросанные вокруг неё «неровные» черточки, которые справа превращаются в ровные строки | `vector line illustration notebook messy lines becoming orderly list` |

I2 убирается, как только пользователь начал печатать, — экран остаётся чистым.

### 7.3. Стоки

Подходящие векторные библиотеки (фильтр «Vectors / SVG», стиль «line art», поиск на английском):

- **unDraw** — open-source, монохром, легко перекрасить в `ink`/`accent` одним CSS-фильтром. Лицензия MIT, атрибуция не нужна.
- **SVGRepo**, **Heroicons**, **Lucide Icons** — для мелких иконок (галочка, телефон, спиннер).
- **Freepik**, **Vecteezy**, **Flaticon** — крупные line-art иллюстрации. ⚠️ Требуют атрибуцию или платную лицензию — перед использованием проверить условия.
- **Noun Project** — одиночные пиктограммы в штриховом стиле.

Для демонстрационного проекта приоритет: **unDraw + Lucide** (без атрибуции, без рисков).

### 7.4. Как внедрять

1. Скачать SVG → прогнать через [SVGO](https://jakearchibald.github.io/svgomg/) (`multipass`, remove-title кроме смысловых).
2. Все залитые цвета заменить на `currentColor`, акцент — на отдельный класс `.ill-accent`.
3. Положить в `public/illustrations/` и импортировать как компонент, **не** как `<img src="https://...">`: стоки должны быть скачаны локально.
4. Внешние CDN-ссылки на картинки запрещены (и ломает офлайн, и не даёт перекрасить).
5. Если иллюстрация со стока не подходит по стилю — использовать локальный placeholder из `public/illustrations/placeholder.svg` и поставить TODO. **Нельзя** тянуть PNG с водяным знаком.

### 7.5. Оптимизация

- Каждая иллюстрация ≤ 8 КБ после SVGO.
- I2 находится в первом экране → грузить сразу (`eager`), `loading="lazy"` не ставить.
- Никаких GIF, Lottie, растровых PNG с альфа-каналом.

## 8. Движение и анимация

Разрешено **только** это:

| Что | Длительность | Кривая |
|-----|--------------|--------|
| Появление карточки результата | 240ms, `opacity 0→1` + `translateY(6px→0)` | `cubic-bezier(0.22, 1, 0.36, 1)` |
| Появление блока предупреждения | 240ms, только `opacity` | та же |
| Тост | 200ms вход / 200ms выход | та же |
| Hover кнопки | 150ms, цвет + 1px | `ease-out` |
| Фокус-обводка | 120ms | `ease-out` |
| Спиннер | 900ms linear infinite rotate | `linear` |

**Запрещено:** пульсация, мигание, «дышащие» фоны, параллакс, появление сверху вниз, анимация текста по буквам, авто-скролл с ускорением, любые hover-эффекты на карточках, автосмена контента.

`prefers-reduced-motion: reduce` → все переходы кроме спиннера = 0ms, спиннер заменяется статичным текстом.

Правило: **анимация объясняет, откуда взялся блок, и всё.** Если она украшает — её не будет.

## 9. Доступность

| Требование | Реализация |
|-----------|------------|
| Контраст | См. §2.3, всё ≥ 4.5:1 для текста |
| Клавиатура | Tab: дисклеймер → textarea → кнопка → Скопировать → Начать заново → телефон доверия. Enter в textarea = перенос строки (не отправка); отправка — `Ctrl/Cmd + Enter` |
| Escape | Очищает фокус с модалок (модалок нет) и сворачивает тост |
| Focus-visible | 3px `accent`, offset 3px, **никогда не `outline: none`** |
| ARIA | `<textarea aria-describedby="hint counter">`; кнопка `aria-busy="true"` при загрузке; результат `role="region" aria-live="polite"`; тост `role="status"`; предупреждение `role="note"` |
| Скринридер | Заголовок страницы = H1, дальше H2 по блокам, без прыжков уровней |
| Размер цели | Все кликабельные ≥ 44×44px |
| Масштаб | Работает при 200% зуме без горизонтального скролла |
| Язык | `<html lang="ru">` |
| Ошибки | Сообщения связаны с полем через `aria-describedby`, не только цветом |
| Touch | Отступы между целями ≥ 8px, чтобы не промахнуться |

## 10. Адаптивность

| Экран | Особенности |
|-------|-------------|
| 320px | H1 18px, отступы по бокам 16px, кнопки на всю ширину, счётчик переносится под поле |
| 375–428px (mobile) | Базовая раскладка, всё в одну колонку, кнопки 52/48px |
| 768px (tablet) | Кнопки «Скопировать» / «Начать заново» встают в строку |
| ≥1200px (desktop) | Колонка 720px, отступы 24/32px, textarea min 180px |

Правила:
- **Mobile-first**: базовые стили — для 320px, `@media (min-width: 768px)` — улучшения.
- Клавиатура не перекрывает поле: `scroll-margin-bottom: 120px` на textarea + автопрокрутка к полю при фокусе.
- `min-height: 100dvh` вместо `100vh`.
- Никаких горизонтальных скроллов ни на одной ширине.
- 100% ширины для textarea и главной кнопки — пользователь не должен попадать мимо.

- [ ] На экране ровно три цвета (плюс их прозрачные версии). Скриншот → пипетка → сверка с §2.1.

- [ ] Line-height 1.7 во всех читаемых блоках.

- [ ] Максимальная ширина контента 720px, на 320px ничего не вылезает.
- [ ] Главная кнопка ≥ 44px по высоте и на всю ширину контейнера.
- [ ] Нет пульсации, мигания, градиентов, цветных теней.

- [ ] `prefers-reduced-motion` работает.
- [ ] При 200% зуме нет горизонтального скролла.
